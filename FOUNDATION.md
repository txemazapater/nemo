# NEMO Foundation

## ¿Qué es NEMO?

NEMO no es un proyecto de software.

NEMO es el sistema que organiza el conocimiento generado durante la creación de proyectos.

## Principios

1. El conocimiento tiene más valor que el código.
2. El código es una consecuencia del conocimiento.
3. Las decisiones deben registrarse.
4. Las hipótesis descartadas también forman parte del conocimiento.
5. Ningún descubrimiento importante debe quedar únicamente en el historial de un chat.

## Dominios de conocimiento

- Corporate
- Research
- Personal

Cada repositorio pertenece a un dominio de conocimiento y reutiliza conocimiento de otros dominios cuando procede.

## El Taquígrafo

NEMO incorpora la figura del Taquígrafo.

Su misión consiste en registrar el contexto, las hipótesis, los experimentos, las decisiones y la evolución intelectual de los proyectos.

No documenta únicamente qué se construyó.

Documenta cómo se llegó hasta ello.

## Lema

> El conocimiento que no se registra, acaba redescubriéndose.
