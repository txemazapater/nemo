# NEMO

NEMO es un mantenedor de conocimiento tecnico y de proyecto: un lugar para convertir conversaciones, decisiones, experimentos y arquitectura emergente en documentacion reutilizable.

El objetivo no es acumular notas, sino construir memoria operativa para proyectos de hardware, software, IA local, asistentes, retrocomputacion y sistemas hibridos.

## Principios

- Capturar decisiones cuando aun estan frescas.
- Separar observaciones probadas de hipotesis.
- Convertir conversaciones en documentos accionables.
- Mantener continuidad entre hilos, repositorios y fases de proyecto.
- Evitar que las ideas se pierdan en chats largos.

## Estructura inicial

- `WORKFLOW.md` - convencion de trabajo para documentar, consolidar y publicar progreso.
- `architecture/` - notas de arquitectura transversal.
- `projects/` - notas por proyecto o linea de investigacion.

## Estado actual

NEMO queda inicializado como repositorio de memoria tecnica. La primera nota de arquitectura recoge el hallazgo del Arduino UNO Q como posible backend grafico residente para un futuro AVP desacoplado del hardware de salida.
